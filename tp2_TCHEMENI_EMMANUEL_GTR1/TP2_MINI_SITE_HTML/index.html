Introduction

ce mini-site a ete cree dans le cadre du cours de TP programmation web.

il permet de decouvrir la creation de plusieurs pages HTML reliees entre elles.

Objectif du mini-site

l'objectif est d'apprendre a structurer un petit projet web avec plusieurs fichiers.

pages disponibles

  • la page presentation contient les informations personnelles de l'etudiant.
  • la page contact contient les informations de contact de l'etudiant.
